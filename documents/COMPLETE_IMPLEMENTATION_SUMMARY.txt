FEATURE: View All Sessions with Registration

DESCRIPTION:
The "View All Sessions" tab now fetches ALL sessions from the main website's
sessions table and displays them with a "Get Registered" option.

KEY FEATURES:
✅ Fetches all sessions from sessions table
✅ Shows sessions grouped by year
✅ Displays session title, description, year badge
✅ Shows "Get Registered" button for unregistered sessions
✅ Shows "Already Registered" badge for registered sessions
✅ Shows "Take Quiz" button for registered sessions
✅ Handles registration with database insertion
✅ Prevents duplicate registrations
✅ Shows success message after registration
✅ Mobile responsive design

================================================================================
                        HOW IT WORKS
================================================================================

USER FLOW:

1. Student clicks "View All Sessions" in sidebar
2. System fetches ALL sessions from database
3. Sessions displayed grouped by year (Year 1, 2, 3, 4)
4. For each session:
   - If NOT registered: Show "Get Registered" button
   - If registered: Show "Already Registered" badge + "Take Quiz" button
5. Student clicks "Get Registered"
6. Form submits with session ID via POST
7. Registration handler processes request:
   - Validates session ID
   - Checks if already registered
   - Inserts into iap_student_sessions table
   - Redirects with success message
8. Success message displays: "Successfully registered for the session!"
9. Session now appears in "View Registered Sessions" tab

================================================================================
                        DATABASE OPERATIONS
================================================================================

FETCH ALL SESSIONS:
Query: SELECT * FROM sessions ORDER BY year ASC, title ASC
Table: sessions
Result: All sessions from all years

CHECK IF ALREADY REGISTERED:
Query: SELECT id FROM iap_student_sessions WHERE student_id = ? AND session_id = ?
Table: iap_student_sessions
Result: Prevents duplicate registrations

REGISTER FOR SESSION:
Query: INSERT INTO iap_student_sessions (student_id, session_id, registration_status) VALUES (?, ?, 'registered')
Table: iap_student_sessions
Result: Creates new registration record
