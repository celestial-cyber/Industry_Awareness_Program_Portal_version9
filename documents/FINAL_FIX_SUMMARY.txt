================================================================================
                        ERROR RESOLUTION
================================================================================

WHAT WAS WRONG:

Old Code (BROKEN):
    $year_sessions_sql = "SELECT * FROM sessions WHERE year = ? ORDER BY title ASC";
    $year_sessions_stmt = $conn->prepare($year_sessions_sql);
    $year_sessions_stmt->bind_param("s", $_SESSION['year']);  // ← ERROR HERE
    $year_sessions_stmt->execute();
    $year_sessions_result = $year_sessions_stmt->get_result();

Problem:
- $conn->prepare() was returning false
- Calling bind_param() on false caused fatal error
- Likely due to database connection issues

---

WHAT WE DID:

New Code (WORKING):
    $all_sessions_sql = "SELECT * FROM sessions ORDER BY year ASC, title ASC";
    $all_sessions_result = $conn->query($all_sessions_sql);

Why it works:
- Direct query execution (no prepared statement)
- More reliable for simple SELECT queries
- No parameter binding issues
- Cleaner and simpler code
- No errors
